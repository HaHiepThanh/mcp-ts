Question 1: Which component of the MCP architecture contains the LLM?
A. Server
B. Host
C. Transport
D. Resource
Answer: B

Question 2: What problem does MCP mainly solve?
A. It trains new language models faster
B. It replaces REST APIs on the web
C. It turns N x M custom connectors between AI apps and data sources into N + M
D. It encrypts data stored in databases
Answer: C

Question 3: In MCP, who decides when a TOOL is called?
A. The model (LLM)

Question 4: Which message format does MCP use?

C. gRPC / Protocol Buffers

Question 5: What is special about a JSON-RPC notification?
A. It always has id 0
