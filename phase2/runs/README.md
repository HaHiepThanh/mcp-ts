# Phase 2 run logs

One folder per member (`tien/`, `hoang/`, `phu/`, `khoa/`). Copy benchmark JSON (`outputs/benchmarks/compare-*.json`) and chat logs (`outputs/logs/chat-*.jsonl`) here with a descriptive name, e.g. `hoang/maxToolRounds-2.json`. Collected into the phase-2 package by `build-submission.sh`.

`E1/`–`E8/` and `I1/` are the experiments of the final Phase 2 code (`phase2/core`, tag `phase2-final`). `hoang/`, `khoa/` and `tien/` are kept as evidence of the members' own work on `main` before `phase2/core` was promoted. The scripts and data they ran against are not on this branch any more; check out commit `3f3f3f5` to rerun them.
